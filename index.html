Privacy Policy

Last updated: September 27, 2026

1. Overview

Bilibili Download Assistant helps users download videos from Bilibili. This policy explains what data the extension accesses and how it is used.

2. Data We Access

  • Bilibili login cookie (SESSDATA) to determine login status and available video quality
  • Current tab information to detect whether the user is on a Bilibili video page
  • Video page metadata needed for downloading

3. How We Use Data

Data is used only to provide video download features. We do not sell personal data.

4. Data Storage

Temporary login-related state may be stored locally in the browser using Chrome storage. Data stays on the user's device.

5. Data Sharing

We do not share user data with third parties.
